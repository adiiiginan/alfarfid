AlfarFID Smart Cleanroom

Centralized RFID Garment Tracking, Sterilization Lifecycle & IoT Monitoring Platform

1. Tentang Sistem

AlfarFID Smart Cleanroom adalah platform perangkat lunak dan Internet of Things (IoT) terintegrasi yang dirancang khusus untuk memantau, mengelola, dan melacak pergerakan serta siklus hidup pakaian kerja steril (cleanroom garments) secara otomatis menggunakan teknologi RFID UHF (Ultra High Frequency).

Di industri farmasi, medis, dan manufaktur semikonduktor dengan standar ketat (seperti cGMP dan ISO 14644), integritas partikel dan sterilitas pakaian kerja adalah parameter vital. AlfarFID hadir untuk mengotomatisasi pengawasan siklus pakaian dari pencucian, sterilisasi autoclave, penyimpanan ruang steril, hingga pemakaian oleh operator.

Tantangan & Solusi yang Dihadirkan:

  • Pelacakan Batas Toleransi Sterilisasi: Mencegah penggunaan pakaian yang telah melebihi batas maksimal siklus autoclave (misal 50 siklus) demi menjaga kerapatan serat kain.
  • Pemisahan Siklus Baju vs Tag: Tag RFID silikon tahan hingga 200 siklus, sedangkan baju umumnya bertahan 50 siklus. Sistem mendukung alur Pindah Tag untuk menghemat anggaran pengadaan.
  • Pencegahan Human Error & Stray-Read: Dilengkapi algoritma Anti Stray-Read (Dwell Time) untuk menolak pembacaan RFID tidak sengaja di dekat reader.
  • Kepatuhan Regulasi & Audit Trail: Seluruh riwayat transaksi data (INSERT, UPDATE, DELETE) tercatat otomatis dengan stempel waktu mikrodetik dan riwayat perubahan nilai.

3. Struktur Basis Data & Entitas Utama

Basis data AlfarFID menggunakan arsitektur UUID Primary Key (CHAR 36) untuk mendukung replikasi dan integritas data multi-plant. Berikut adalah entitas utama:

Nama Tabel Kunci Utama Deskripsi & Relasi Penting
garments garment_id (UUID) Menyimpan kode baju (GRM001), ukuran, divisi, status (active/in_repair/damaged/retired), stage terkini, dan total siklus.
tags tag_id (UUID) Menyimpan UID tag RFID fisik (tag_uid), total_cycles_used, rated_max_cycles (default 200), dan status.
tag_garment_bindings binding_id (UUID) Riwayat relasi many-to-many historis antara tag dan garment. Flag is_current menandai tag aktif.
devices device_id (UUID) Data reader ESP32, MAC address, hash API key, lokasi fisik, status online/offline, dan timestamp heartbeat.
scan_events event_id (UUID) Log transaksi pembacaan RFID: event_type, stempel waktu mikrodetik, cycle_count_after, dan relasi ke device & user.
alerts alert_id (UUID) Notifikasi sistem otomatis: cycle_warning (90%), cycle_exceeded (100%), device_offline, dan tag_wear_warning.
divisions division_id (UUID) Divisi operasional (Produksi Steril, QC, Packaging) lengkap dengan kode warna visual (color_hex).
garment_categories category_id (UUID) Kategori baju (Coverall, Hood, Booties) dan default batas siklus autoclave (default_max_cycle).
audit_logs log_id (UUID) Riwayat perubahan data: aksi (INSERT/UPDATE/DELETE), pelaku (changed_by), dan JSON diff nilai lama vs baru.
users user_id (UUID) Pengguna sistem dengan role-based authorization (admin, operator, viewer).

4. Siklus Hidup Pakaian (State Machine & Stage Flow)

AlfarFID menggunakan prinsip Server-Determined Stage Flow. Perangkat pembaca RFID (ESP32) tidak perlu menentukan jenis transaksi secara manual. Perangkat cukup mengirimkan UID tag yang terbaca, dan server secara otomatis menentukan transisi stage berdasarkan kondisi baju saat itu:

Stage Asal Event Scan Stage Tujuan Min Dwell (Anti Stray-Read) +Siklus
siap_digunakan usage_checkpoint sedang_dipakai 0 menit (Bebas diambil kapan saja) Tidak
sedang_dipakai pre_autoclave pre_autoclave 9 jam (540 menit pemakaian + laundry) Tidak
pre_autoclave post_autoclave siap_digunakan 30 menit (Proses sterilisasi autoclave) +1 (Siklus Bertambah)

Mekanisme Proteksi Anti Stray-Read (Dwell Time):

Untuk mencegah salah baca ketika baju hanya melintas di dekat antena reader RFID, sistem memberlakukan batas waktu minimal keberadaan baju di setiap stage (Min Dwell). Bila scan diterima sebelum batas waktu terpenuhi, server akan menolak dengan pesan sisa waktu (misal: GRM001 4.5 jam lagi).

5. Modul & Fitur Utama Aplikasi

5.1 Dashboard & KPI Realtime

Menyajikan ringkasan metrik instan: Total Garment Aktif, Tag Aktif, Item Kritis (≥90% siklus), Scan Hari Ini, dan Status Reader Online. Dilengkapi tabel live feed 8 aktivitas scan sterilisasi terakhir.

5.2 Master Data Garment & Tag RFID

  • Auto-Generate Kode Garment: Pembuatan kode otomatis berurutan (GRM001, GRM002, dst) yang terkunci agar mencegah duplikasi.
  • Mode Registrasi RFID Global: Mode penangkapan scan nirkabel dari reader ESP32 mana pun untuk registrasi tag baru tanpa ketik manual.
  • Pagination & Sorting: Tabel data dilengkapi pagination 10 baris per halaman dan data terbaru tampil di posisi teratas.

5.3 Sirkulasi Pintar: Pindah Tag vs Ganti Tag

  • Pindah Tag (/admin/pindah-tag): Dijalankan ketika kain baju rusak/robek namun tag RFID masih memiliki sisa siklus. Tag dipindahkan ke baju baru yang belum bertag.
  • Ganti Tag (/admin/ganti-tag): Dijalankan ketika tag RFID aus/rusak namun kain baju masih bagus. Baju dipasangkan tag baru tanpa mereset riwayat siklus baju.

5.4 Early Warning System & Alerts

  • Warning Alert (≥90% batas siklus): Memberikan aba-aba persiapan pengadaan.
  • Critical Alert (≥100% batas siklus): Notifikasi merah berdenyut; pakaian wajib segera dipensiunkan (retired).
  • Alur Penanganan: Tombol Acknowledge (diketahui operator) dan Resolve (diselesaikan dengan catatan petugas & stempel waktu).

5.5 Analytics & Prediksi Waktu Pensiun

Menyediakan grafik tren pembacaan RFID harian/mingguan, distribusi umur baju, distribusi keausan tag RFID silikon, serta prediksi jumlah baju yang akan retired dalam 7 dan 14 hari ke depan berdasarkan frekuensi penggunaan rata-rata.

5.6 Audit Trail Terintegrasi

Mencatat seluruh rekam jejak manipulasi data (INSERT, UPDATE, DELETE) pada seluruh tabel master, lengkap dengan panel ekspansi perbandingan nilai lama vs nilai baru (JSON diff) dan filter pencarian berparameter.

5.7 Manajemen Perangkat IoT & API Key

Mendaftarkan unit ESP32 reader baru, menetapkan lokasi fisik, memantau detak jantung (heartbeat), serta mengelola kunci API rahasia (af_dev_...) lengkap dengan fitur Regenerate Key.

6. Protokol Integrasi IoT (ESP32 RFID Reader)

Perangkat ESP32 berkomunikasi dengan server Laravel menggunakan format REST API JSON standar HTTP/HTTPS.

1. HTTP Header Autentikasi Wajib:

POST /scan-events HTTP/1.1 Host: 192.168.1.106:8000 Content-Type: application/json X-Device-Mac: 24:6F:28:AB:CD:EF X-Api-Key: af_dev_7a9f8b2c4e6d1a3b5c7e9f0a

2. Request Payload JSON:

{ "tag_uid": "E2801170000002157A89BC12" }

3. Contoh Respons Sukses (HTTP 201 Created):

{ "message": "Scan berhasil dicatat.", "mode": "operational", "data": { "event_id": "d7e1c4a2-4f8b-4c2e-9a1b-3c4d5e6f7a8b", "garment_code": "GRM001", "division_name": "Produksi Steril", "tag_uid": "E2801170000002157A89BC12", "event_type": "post_autoclave", "cycle_count_after": 12, "max_cycle_limit": 50, "new_stage": "siap_digunakan", "threshold_status": "ok" } }

7. Panduan Instalasi & Konfigurasi Server

  • Pastikan PHP ≥ 8.1 dan MySQL/MariaDB sudah aktif di XAMPP.
  • Jalankan composer install di folder proyek.
  • Sesuaikan konfigurasi koneksi database di file .env (DB_DATABASE=alfarfid).
  • Eksekusi migrasi database dan data awal: php artisan migrate --seed
  • Jalankan web server: php artisan serve --host=0.0.0.0 --port=8000
