AlfarFID Smart Cleanroom

Entity Relationship Diagram (Database Schema)

Informasi Database: Berisi 13 tabel relasional inti sistem AlfarFID Cleanroom dengan primary key berbasis UUID (CHAR 36). Menghubungkan entitas fisik (Garment, Tag UHF, Perangkat IoT ESP32) dengan sesi sterilisasi autoclave, histori pembacaan (Scan Events), peringatan (Alerts), dan Audit Log regulasi.
Visualisasi Skema Basis Data (Mermaid ERD) Gunakan scroll mouse atau tombol di atas untuk zoom

    users {
        uuid user_id PK
        string full_name
        string email UK
        string password_hash
        string role
        boolean is_active
        timestamp created_at
        timestamp updated_at
    }

    garment_categories {
        uuid category_id PK
        string category_name UK
        text description
        int default_max_cycle
        timestamp created_at
    }

    tags {
        uuid tag_id PK
        string tag_uid UK
        string tag_type
        string manufacturer
        int rated_max_cycles
        int total_cycles_used
        string status
        date date_first_deployed
        text notes
        timestamp created_at
        timestamp updated_at
    }

    garments {
        uuid garment_id PK
        string garment_code UK
        uuid category_id FK
        string size
        uuid current_tag_id FK
        int max_cycle_limit
        int current_cycle_count
        string status
        date date_first_used
        date date_retired
        timestamp created_at
        timestamp updated_at
    }

    tag_garment_bindings {
        uuid binding_id PK
        uuid tag_id FK
        uuid garment_id FK
        timestamp bound_at
        timestamp unbound_at
        uuid bound_by FK
        string unbind_reason
        boolean is_current
        char active_tag_uid UK
        char active_garment_uid UK
    }

    autoclave_machines {
        uuid machine_id PK
        string machine_name
        string location
        date install_date
        string status
    }

    autoclave_sessions {
        uuid session_id PK
        uuid machine_id FK
        date session_date
        smallint session_number
        timestamp start_time
        timestamp end_time
        uuid operator_id FK
        string status
    }

    devices {
        uuid device_id PK
        string device_name
        string location
        string mac_address UK
        string api_key_hash
        string status
        timestamp last_heartbeat_at
        date installed_at
        timestamp created_at
    }

    scan_events {
        uuid event_id PK
        uuid tag_id FK
        uuid garment_id FK
        uuid session_id FK
        uuid device_id FK
        string event_type
        timestamp scan_timestamp
        int cycle_count_after
        string location
        timestamp created_at
    }

    alerts {
        uuid alert_id PK
        uuid garment_id FK
        uuid tag_id FK
        uuid device_id FK
        string alert_type
        string severity
        text message
        timestamp triggered_at
        timestamp resolved_at
        uuid resolved_by FK
        string status
    }

    notifications {
        uuid notification_id PK
        string category
        text message
        timestamp created_at
    }

    audit_logs {
        uuid log_id PK
        string table_name
        uuid record_id
        string action
        json old_value
        json new_value
        uuid changed_by FK
        timestamp changed_at
    }

    reports_generated {
        uuid report_id PK
        string report_type
        uuid generated_by FK
        date date_range_start
        date date_range_end
        string file_path
        timestamp generated_at
    }

Daftar Entitas & Deskripsi Relasi

Nama Tabel Primary Key Foreign Key & Relasi Fungsi Utama
garments garment_id (UUID) category_id, current_tag_id Menyimpan data fisik baju, ukuran, limit siklus sterilisasi, dan jumlah siklus terkini.
tags tag_id (UUID) - Menyimpan UID tag RFID fisik UHF, toleransi siklus (±200x), dan total siklus tag.
tag_garment_bindings binding_id (UUID) tag_id, garment_id, bound_by Mencatat riwayat bongkar-pasang tag ke baju (memungkinkan re-use tag ke baju baru).
scan_events event_id (UUID) tag_id, garment_id, session_id, device_id Log pembacaan RFID realtime (pre_autoclave, post_autoclave, checkpoint gowning).
devices device_id (UUID) - Data modul reader ESP32 (MAC address, hashed API key, heartbeat, status online).
autoclave_sessions session_id (UUID) machine_id, operator_id Sesi operasional mesin autoclave sterilisasi per tanggal dan nomor batch.
autoclave_machines machine_id (UUID) - Master mesin autoclave sterilisasi dan lokasinya di fasilitas pabrik.
alerts alert_id (UUID) garment_id, tag_id, device_id, resolved_by Early warning jika garment/tag mendekati limit siklus atau perangkat reader offline.
users user_id (UUID) - Pengguna web dengan otorisasi RBAC (admin, operator, qa_supervisor, auditor).
audit_logs log_id (UUID) changed_by Jejak audit regulasi (cGMP/ISO 14644) perubahan data (diff JSON nilai lama vs baru).
