Matriks Use Case Berdasarkan 2 Role

Kode Nama Fungsional Use Case Superadmin Staff ESP32 Reader Keterangan / Relasi
UC-01 Login & Kelola Profil ✓ ✓ - Autentikasi akun dan ubah password mandiri.
UC-02 Manajemen Pengguna (Superadmin & Staff) ✓ ✗ - Membuat, mengubah, dan menonaktifkan akun.
UC-03 Kelola Master Garment, Kategori & Divisi ✓ ✗ - Registrasi baju (auto kode GRM001..), limit siklus.
UC-04 Kelola Tag RFID & Mode Registrasi ✓ ✗ ✓ Scan tag baru secara nirkabel dari reader manapun.
UC-05 Sirkulasi Pintar (Pindah / Ganti Tag) ✓ ✗ - Pemisahan alur kain rusak vs tag aus. <<include>> UC-13.
UC-06 Pembacaan RFID (Sterilisasi / Gowning) Otomatis ✓ ✓ Scan baju di portal antena. <<include>> UC-08, UC-09.
UC-07 Manajemen Perangkat & API Key ✓ ✗ - Daftar reader ESP32 baru dan regenerasi API key.
UC-08 Otentikasi Perangkat (MAC & Key) Diproses Otomatis oleh Middleware Server Memvalidasi header X-Device-Mac & X-Api-Key.
UC-09 Validasi Anti Stray-Read (Min Dwell) Diproses Otomatis oleh Logika Server Mencegah double scan (laundry 9 jam, autoclave 30 menit).
UC-10 Monitoring Realtime & Scan Events ✓ ✓ - Dashboard live KPI & feed aktivitas scan detik-per-detik.
UC-11 Tangani Alerts Siklus & Reader Offline ✓ ✗ - Acknowledge & resolve peringatan siklus kritis (<<extend>>).
UC-12 Analisis Tren & Prediksi Pensiun ✓ ✗ - Grafik analitik tren autoclave dan perkiraan pensiun kain.
UC-13 Peninjauan Log Audit Trail (cGMP) ✓ ✗ - Pemeriksaan jejak perubahan data forensik (ISO 14644/cGMP).
UC-14 Generate & Unduh Laporan ✓ ✓ - Ekspor riwayat scan & status pakaian ke Excel/CSV/PDF.
